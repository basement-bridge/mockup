Option C overview

History in context: phone

History opens as a bottom sheet from the clock on the thing you are looking at. It starts scoped to that thing. The breadcrumb widens it. Pick where you are:

  • Default path loads the host screen only. The clock is an icon with no data behind it.
  • Deferred: the journal for that one scope is fetched on the first tap of the clock (this file, hc.js and hc.css are the lazy chunk, about 43 KB unminified). Search runs on what is already loaded for the scope. Widening fetches the wider scope once. Days load 3 at first, then 5 per tap.
  • Phone-only layout: sheet, scope chips scroll sideways, filters behind one button, undo under the row text.
