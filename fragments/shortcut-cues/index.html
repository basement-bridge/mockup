Global shortcut cues

Owner, 11 October 2026: Shift ? turns on the shortcut cues from anywhere: every screen, flyout, modal and sub-screen. Mockup only; the notes are in docs/knowledge/shortcut-cues.md.

PantryWith the item flyoutInside the Add modalSettings, full screenHousehold sub-screenHistory (no keys of its own)
What it does
  • Shift ? (or H) opens the Shortcuts list on any layer; again closes it. With the cue switch Off the cues come on for this visit.
  • Never fires in a text box: ? types a ?. Ignores IME composing, key repeat and Ctrl/Cmd chords; reads the character, so non-US layouts work.
  • Ctrl Esc (Cmd on a Mac) closes the list first, then the panel behind it.

Default path loads: one small script per page that only listens for the key; the list is built on the first press. Nothing is stored except the existing cue switch.
