Every look, both modes

Each look's light half (left) and dark half (right), straight from the app's tokens. Nothing was invented: Kitchie is Day and Night; the nine themes already carry both halves (Marmalade, Herb Garden and the six light-first ones have a dark half in ALT; Blueberry is dark-first with a light half).

What is drawn (Proposals unless marked)
  • Placement (owner: beside the picker). A Mode row directly above Theme, same label style, so the two read as one pair: how it looks (mode), then whose colours (theme). Phone: full-width three-segment control. Desktop: the same control inline, to the left of Theme.
  • Three visible choices (owner). System (selected by default), Light, Dark. System has a half-circle icon, Light a sun, Dark a moon, so the choice reads at a glance. The control is a radio group using the app's .seg2; every target is 44px high on the phone.
  • A line says what is in effect. Under the control: "Following your device, which is dark now." for System; "Always light." / "Always dark." otherwise. It answers "why is it dark?" without a help page.
  • Theme swatches show the half in use (they redraw when the mode changes), and the theme name is written once underneath as today.
  • Saves the moment it changes, no Save button, like the theme and the other Looks controls.
  • Mode is independent of theme. Picking a theme keeps the mode; picking a mode keeps the theme. Option 3 on the issue (fold mode into the theme value) is not drawn: it brings back the coupling this change removes.
