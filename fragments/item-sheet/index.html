Item sheet, four layouts

Fragment. Tap an item on Pantry and a sheet rises from the bottom to about half the screen, with that item's details and a way to edit. Four layouts to choose from. Same item, same actions, different lead. Owner chose option 2, Tile grid (8 Oct 2026); it is now in the household flow (flows/household/). The other three stay here for reference.

11 Oct 2026: the level icon on these layouts is a battery, not a drop (owner, item-edit-flyout decision 94). The symbol is the same everywhere it is drawn; the banded, coloured version is in flows/household/ and fragments/item-edit-flyout/.

Counted: has an amount and unit, so it can step down. Level-only: freeform like salt, where nothing can be decremented, so the level is what you change.
