Item notes

Kitchie #986. Quiet by default: a note is one muted line, only on rows that have one. Mockup only.

Proposals
  • Household list: the note takes the row's muted line (where the location shows), two lines at most. Rows without a note are unchanged.
  • No pill, chip or icon per row. "This trip" shows only on the add sheet.
  • Shopper link: the note under the name, up to two lines, read-only. The swap button reads "Got substitution?".
  • Plain text, about 200 characters, one note per item, shared by the household. Buying writes the row's note to the Pantry.
Open
  • A running-low row is not stored today: it reads the Pantry note live, stored once edited.
  • Should a trip-only edit leave the Pantry note alone on buy? Drawn as no.

Loads: static HTML, the app's own CSS, no script except the add sheet's.
