Item notes

One free-text note on an item. The name stays plain ("cucumber"); the note carries the detail ("Persian or Lebanese, the tasty kind"). It lives on the Pantry item and on the shopping row, and the two stay in step. Kitchie #986. Mockup only, nothing built.

The rule, in one line: whatever note is on the row when you buy it becomes the Pantry item's note. Nothing is overwritten unseen, because the Pantry note is shown pre-filled when you add the item.

Proposals (mine; the owner was silent)
  • Plain text, about 200 characters, no formatting.
  • One note per item, shared by every household member. It reads the same on the shopper link, read-only.
  • A note edit is a History entry, so Undo restores the old note (the "bought" path included).
  • Clearing the box on a row and buying clears the Pantry note too. The helper line says so before it happens.
  • Keeping the add sheet as it is when there is no Pantry note: the box is empty and says "Becomes the Pantry note when you buy it".
Open
  • Where does a trip-only edit on a running-low row live, since that row is not stored today (issue question 1)? Drawn as: stored only once edited.
  • Should "Just this trip" ever mean the Pantry note is left alone on buy? Drawn as no, to follow the owner's rule: what is on the row when bought wins.
