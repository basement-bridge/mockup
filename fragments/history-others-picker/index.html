History: the Others picker and the card wording

Kitchie #1103. Owner, by voice with a screenshot, 23 and 24 Oct 2026: the top is just Mine | Others (no People). Others opens a dropdown of the other members, each with an initial circle, the name as a link, and a count, plus a way to select or deselect them. The name is a link with a function, as it is in Kitchie today. The card is headed Recent changes and reads 72 changes: 71 by you, 1 by Sleepy Gecko.

Decided (owner, 24 Oct 2026)
  • The dropdown starts closed.
  • Unticking the last ticked person reticks everybody.
  • Pressing a name leaves only that person ticked.
  • The card wording is in the same issue.
Proposals (owner was silent)
  • Everyone starts ticked (nothing narrowed). A tick box per row is the select or deselect.
  • A tick keeps the dropdown open (it is a toggle); a name opens only that person and closes it.
  • With one other member the dropdown is still drawn, for the same look every time.
  • The person bar reads "Only changes by Matilda, Sleepy Gecko" when several are ticked.
  • The Others count is the changes of the ticked people.
Open questions
  • Should the tick or the name be the larger tap area on a phone? Both are 44px high here; the name takes the room.
  • In the Settings window (desktop) the name underlines on hover today; here it is underlined at rest so a phone shows it is a link. Keep at rest, or hover only?
  • The card's line when people are ticked: today "N changes in all, shown below for ..."; here it keeps "77 changes: ..." and the person bar says who is shown. OK?
