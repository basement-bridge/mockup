What was wrong, what changed, how to read this page
  • What was wrong (visible): each result was a tall block (title, scope pill, “Exact match”, AFFECTS paragraph, LIVES IN path, a full-width Open button, sometimes a control row). Two or three results per screen, shouty labels, an accent bar and tint on the first one, and nothing to scan.
  • What all four do instead: one or two lines per result, 44px rows, matched words highlighted (no “Exact match”), the plain-language sentence only when asked for, scope as an icon (long-press an icon, or the i button, for what it means), search only as a quiet dashed-magnifier icon, a shortcut that is already pinned as an icon only (no word). Six or more results on a 390 by 844 screen.
  • Same index, same engine: the real 51 entries and their synonyms (../settings-redesign/search-index.js, 52 minus Emoji, which the owner removed). Type in any box, press a preset, or try a typo. Text sizes to +30% and Light/Dark are in the bar.
  • Search from every page (owner addition). Start on Settings, Looks, Household, Preferences or Kitchen setup (“Start page”), open the search with the magnifier in the header, and the same words rank differently: the page you are on is listed first as On this page, the rest as Everywhere else. Tap a result: it opens its page and the row flashes; Back returns to the results you left.

Why B (designer’s recommendation)

B is the only option where the search result is the setting for the searches people actually make (bigger text, bell, motion, check amounts). It keeps every row at two lines, shows scope as one small icon, and needs no learned icon set beyond four. C is the runner-up if the owner wants one hero answer; D if the app wants more personality. A is the fallback with the fewest moving parts.

Page-scoped ranking (SR-P23, proposal)

Score every setting as today (exact, old name, phrase, words, typos). A result is On this page when it lives on the page the person is on and scores at least a fifth of the best score (and 20 points), so a stray partial hit on this page never outranks a strong answer elsewhere. On this page is listed first; each list keeps the global order. From the Settings front there is no “this page”. If nothing on this page matches, one quiet line says so. Where each setting lives is a Proposal for the History and activity bell rows: both are filed under Household here.

Loads

Default path: theme.css, theme.js, shared.css, ssr.css (small), ssr.js. Deferred: ../settings-redesign/search-index.js (about 7 KB gzipped), fetched on first focus, typing, preset or when a start page needs it. Nothing is stored.
